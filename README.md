# 🎓 iFlow — Sistema de Gestão de Ocorrências Acadêmicas

🚀 Plataforma completa para registro, acompanhamento e gestão de ocorrências acadêmicas e disciplinares.

O iFlow está sendo desenvolvido como parte da disciplina de **Web 3**, com foco na construção de uma aplicação moderna utilizando arquitetura fullstack com Next.js e Nest.js.

O sistema permite que professores, coordenadores, equipe pedagógica e responsáveis acompanhem todo o ciclo de uma ocorrência — desde o registro até a resolução, garantindo rastreabilidade, organização e transparência.

---

## 🧩 Arquitetura do Projeto

Este repositório está dividido em duas aplicações principais:

* 🔙 **Backend (API)** → Nest.js
* 🎨 **Frontend (Web)** → Next.js

📁 Estrutura:

```
/back   → API (Nest.js)
/front  → Interface Web (Next.js)
```

## 👥 Perfis do Sistema

O sistema contempla diferentes tipos de usuários:

* 👨‍🏫 Professor
* 👩‍💼 Coordenador
* 🧠 Equipe Pedagógica
* 🎓 Aluno
* 👨‍👩‍👧 Responsável
* ⚙️ Administrador

---

## 🔄 Principais Funcionalidades

* Registro de ocorrências
* Anexos (evidências)
* Controle de status
* Validação de ocorrências graves
* Dashboard gerencial
* Auditoria e rastreabilidade (LGPD)
* Notificações automáticas

---

## 🧭 Jornadas de Usuário

### 👨‍🏫 Professor

* Registrar ocorrência
* Atualizar status
* Anexar evidências

### 🎓 Aluno

* Visualizar ocorrências
* Confirmar ciência

### 👨‍👩‍👧 Responsável

* Acompanhar ocorrências do aluno
* Receber notificações

### ⚙️ Administrador

* Gerenciar usuários
* Auditoria e logs
* Validar ocorrências graves
* Monitorar dashboard
